## 🌟 Overview

**Pact Ventures** is a dynamic export-import platform based in Tamil Nadu, South India. This repository contains the source code for the official landing page, designed with a focus on **pixel-perfect mobile responsiveness**, **high-fidelity UI alignment**, and **smooth scroll animations**. 

The UI exactly mirrors premium Canva prototypes, utilizing creative CSS techniques for absolute positioning, overlapping elements, and custom typography to create a massive visual impact.

## ✨ Features

- 📱 **Mobile-First Design**: Custom hooks (`useIsMobile`) ensure a flawless, app-like experience across all smartphone viewports.
- 🎨 **Premium Aesthetics**: Split-screen gradients, custom typography (`Great Vibes`, `Patrick Hand`), and parallel flex layouts that break the grid beautifully.
- 🚀 **Framer Motion Animations**: Elegant, viewport-triggered smooth scroll reveal animations (`opacity`, `y-axis sliding`) integrated globally via a custom wrapper.
- ⚡ **Blazing Fast**: Powered by **Vite** with optimized asset delivery and module federation.
- 🌐 **Production Ready**: Fully configured for **Netlify** with built-in SPA routing safeguards (`_redirects`, `netlify.toml`).

## ⚙️ Local Development

Clone the repo and start the development server:

```bash
git clone https://github.com/Rishidevlx/agri-about.git
cd agri-about
npm install
npm run dev
```

## 🚀 Deployment

This project is configured for instant deployment on **Netlify**. 

1. Connect this GitHub repository to your Netlify account.
2. Build command: `npm run build`
3. Publish directory: `dist`
*(All configurations are automatically handled via the included `netlify.toml` and `public/_redirects` files)*
